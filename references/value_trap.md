# 价值陷阱识别清单

"便宜"不是结论，是问题。当 comps 显示标的相对 peer 显著折价时，必须逐项排查，不能默认"市场错了"。

## 折价的可能原因（先归因，再下注）
1. **结构性劣势**：份额流失、产品代际落后、管理层失信——折价合理，不是机会。
2. **流动性折价**：小盘 / 跨市场标的，折价来自可交易性，不是基本面。
3. **会计质量**：激进确认收入、表外负债、持续一次性收益粉饰——折价是对风险的定价。
4. **周期位置**：周期顶部显得便宜（EPS 高点）、底部显得贵（EPS 低点）——用正常化口径重算。
5. **真正错误定价**：信息差 / 短期情绪 / 指数调仓冲击——这才是可下注的"便宜"。

## 触发"不碰"的硬信号
- 折价伴随连续 2+ 季营收/份额下滑；
- 折价伴随治理红灯（审计换所、高管密集减持、监管调查）；
- 折价但自由现金流持续为负且无解；
- DCF 下行地板也支撑不了当前价（见 `dcf-quick`）。

## 输出纪律
结论必须写明：**折价来源 + 是否可下注 + 触发重估的变量**。只报"便宜"不报原因 = 无效输出。
